## Testes
Ver os resultado dos testes em separado do docker compose.

Para correr os testes unitários, na pasta raiz do projeto:

**Linux / macOS:**
```bash
./mvnw test
```

**Windows (PowerShell):**
```powershell
.\mvnw.cmd test
```

Para correr os testes com verificação de cobertura (≥80%):

**Linux / macOS:**
```bash
./mvnw verify
```

**Windows (PowerShell):**
```powershell
.\mvnw.cmd verify
```
